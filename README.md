# 🍳 TastyTrack Pro

**TastyTrack Pro** is a sleek, modern, single-file Full-Stack web application designed to help users manage their kitchen recipes and track fridge inventory effortlessly. Built with **React**, **Tailwind CSS**, and **LocalStorage Persistence**, it offers a smooth, reactive, and app-like user experience.

---

## ✨ Features

- 📊 **Smart Dashboard**: Real-time stats on recipes, total inventory, and instant alerts for expiring items.
- 🥗 **Recipe Explorer**: 
  - Filter recipes by categories (*Breakfast, Lunch, Dinner*).
  - Search recipes by name or ingredients.
  - Interactive popup modal with step-by-step instructions and ingredient lists.
- 🧊 **Smart Fridge Inventory**: 
  - Visual color-coded progress bars for item freshness.
  - Expiry warning badges (`Days Left`).
  - Ability to delete items on the fly.
- 💾 **Local Storage Persistence**: Acts like a full-stack app by keeping your inventory and recipe updates saved in the browser.
- 🎨 **Beautiful UI/UX**: Designed with smooth animations, custom scrollbars, and a modern sidebar interface.

## 🛠️ Tech Stack

- **Frontend**: React 18 (Standalone via CDN)
- **Styling**: Tailwind CSS, Custom CSS Animations
- **Icons**: Custom SVG Icons (Lucide-inspired)
- **State & Data**: React Hooks (`useState`, `useEffect`) + Browser `localStorage`
- **Compiler**: Babel (`@babel/standalone`)
